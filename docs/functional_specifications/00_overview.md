# プロジェクト全体概要

## 1. プロジェクト名
BandLink (バンドリンク)

## 2. コンセプト
ミュージシャン同士が、楽器・ジャンル・目的・場所に基づいて最適なパートナーをスワイプ形式で探せるマッチングプラットフォーム。

## 3. 主要画面構成
1. **探す (Discover)**: ユーザーカードをスワイプして Like/Nope を選択。
2. **マッチ (Matches)**: 相互Likeが成立したユーザー一覧とチャット。
3. **プロフィール (Profile)**: 自身の情報編集、活動拠点の設定。
4. **Pro版 (Premium)**: 有料プランの紹介と購入。

## 4. 共通システム
*   **認証**: Supabase Auth によるメール/パスワード認証、ソーシャルログイン。
*   **ログ管理**: `src/lib/logger.ts` による一元管理。
*   **エラー処理**: ユーザー向けアラート表示と開発用ログ出力。
*   **ステータス同期**: 通信の度にサブスクリプション期限をチェックする自動更新機能。
