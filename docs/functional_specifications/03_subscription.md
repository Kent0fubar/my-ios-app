# 購読 (Subscription) 機能仕様書

## 1. 課金プラン体系
RevenueCat を通じた iOS アプリ内課金によるマネタイズ。

### 1-1. プラン比較表
| 特典 | 無料 (Free) | Premium版 | Pro版 |
| :--- | :---: | :---: | :---: |
| スワイプ制限 | 30回/日 | **無制限** | **無制限** |
| 広告 | 表示あり | **非表示** | **非表示** |
| 高度なフィルター | × | **○** | **○** |
| プロフィールブースト | × | × | **○** |
| 既読確認機能 | × | × | **○** |

## 2. 権限管理 (フラグ管理)
データベース上の以下の boolean フラグで制御を行う。
*   `is_premium`: `true` の場合、Premium 以上の特典を付与。
*   `is_pro`: `true` の場合、Pro 版固有の特典（ブースト）を付与。

## 3. サブスクリプション期限の自動同期
不整合（期限切れなのに機能が使えてしまう等）を防ぐための自動同期処理。

### 3-1. 同期タイミング
*   `getMyProfile` 呼び出し時（アプリ起動時や画面遷移時）。
*   課金成功時。

### 3-2. クリーンアップ条件
以下のいずれかに該当する場合、`is_premium` と `is_pro` を強制的に `false` に更新する。
1. **期限切れ**: 現在時刻が `subscription_expires_at` を超過している。
2. **情報の欠落**: プレミアムまたは Pro のフラグが立っているにも関わらず、有効期限が保存されていない。

## 4. モックモード
開発環境（Expo Go / Simulator）では RevenueCat の通信をエミュレートし、常に購入が成功したものとして動作する。

## 5. システムの信頼性とセキュリティ

### 5-1. 通信時バリデーション
クライアントサイドだけで権限を判断せず、重要なAPI（スワイプ、メッセージ送信など）の実行直前にサーバーサイドの値を再検証、または `syncSubscriptionStatus` を実行することで、不正な機能利用を徹底的に排除している。

### 5-2. 優雅な機能制限（Graceful Degradation）
期限切れが検知された際、ユーザーを即座にログアウトさせるのではなく、機能フラグのみを下ろすことで、無料会員としての利用を継続させつつ、スムーズな再購読へと誘導する設計を採用。
